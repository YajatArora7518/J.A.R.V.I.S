# Viewer verification sample

`RobotExpressive_sample.glb` is the CC0 RobotExpressive model by Tomás Laulhé,
with modifications by Don McCurdy. It is a viewer test asset, **not** a generated
Iron Man, Tony Stark or Virat Kohli model.

Source: https://raw.githubusercontent.com/mrdoob/three.js/r164/examples/models/gltf/RobotExpressive/RobotExpressive.glb

Credit and license: https://threejs.org/examples/webgl_animation_skinning_morph.html

It contains 14 mesh definitions and 14 animation clips. JARVIS can import it
through its regular Attach button or the 3D Studio import picker.
